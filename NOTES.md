# NOTES — сайт-визитка Сергея Ча (сессионная гитара)

Этот файл для Claude и для меня: прочитать в начале каждого нового чата про сайт,
обновлять после каждой правки (раздел «История» и «Что дальше»).

## Что это
- Одностраничный сайт-визитка: живая гитара на заказ (удалённая запись партий).
- Адрес: GitHub Pages, https://chasb1974.github.io/guitar/
- Репозиторий: chasb1974/guitar, ветка main. Публикация — просто пуш в main.
- Аудитория: продюсеры и авторы, в том числе зарубежные; главное предложение —
  заменить ИИ-гитару (Suno, Udio) живой партией.

## Структура файлов
- `index.html` — весь сайт одним файлом (HTML + CSS + JS внутри).
- `img/` — фото: сцена, студия, Fender, постеры к видео, обложки (альбом 2012, саундтрек).
- `media/` — видео `funk.mp4`, `nylon.mp4`; аудио `rock-lead.mp3`, `nylon-mix.mp3`, `funk-demo.mp3`.

## Как устроен index.html
- Два языка RU/EN переключателем вверху. Русский текст — в самом теге,
  английский — в атрибуте `data-en="..."`. При правке текста менять ОБА.
  Выбранный язык запоминается в localStorage.
- Секции (id): `top` (шапка с анимацией струн на canvas и кнопкой «Звук струн»),
  `portfolio` (видео), `audio` (плеер треков), `free` (бесплатный фрагмент),
  `skills` (что записываю), `how` (как работаем), `about` (о себе),
  `gear` (студийный сетап), `contacts`.
- Плавающая кнопка «Написать» (Telegram) внизу справа.
- Google Analytics: G-BYTNCVJTQQ.
- Шрифты: Unbounded, Manrope, IBM Plex Mono (Google Fonts).
